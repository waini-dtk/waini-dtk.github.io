Pemulihan akses akun

Reset password belum dapat dilakukan otomatis.
Akun WAINI saat ini menggunakan alamat email internal berdasarkan NIK dengan domain khusus yang tidak menerima email. Karena itu, tautan reset email Firebase tidak dapat dikirim ke akun tersebut.

Jika lupa password

  1. Hubungi Super Admin WAINI.
  2. Super Admin melakukan reset password melalui pengelolaan Firebase Authentication.
  3. Setelah password baru diberikan secara aman, segera login dan jangan membagikan password kepada orang lain.
